
# NorthPeak Digital

NorthPeak Digital is a modern, responsive one-page agency website developed as part of the Digital Heroes Web Development Internship Qualification Task. The project is built using HTML5, CSS3, and Vanilla JavaScript with a focus on responsive design, semantic HTML, accessibility, clean code, and performance optimization.

## Features

- Responsive Design
- Modern UI
- Services Section
- Testimonials
- Pricing Plans
- Contact Form with Validation
- Smooth Scrolling
- Mobile Navigation
- Semantic HTML
- Performance Optimized

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
